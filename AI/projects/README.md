# Projects

Create one folder per project:

```text
projects/
└── example-project/
    ├── project.md
    ├── architecture.md
    ├── design-system.md
    ├── stack.md
    ├── commands.md
    ├── known-issues.md
    └── decisions.md
```

Do not copy an entire repository into this directory. Store concise project context and links to the actual repository.

Project files must distinguish verified facts from open questions. Update them when the source repository changes, and delete empty scaffolds that provide no usable context.
