# Frontend Rules

Migration note: reusable review and implementation guidance from this file was consolidated into `AI/rules/01-general.md`, `AI/rules/03-editing.md`, and `AI/rules/04-review.md`. Original guidance is preserved below.

- Use semantic HTML before adding ARIA.
- Preserve keyboard access and visible focus states.
- Support responsive layouts without relying on fixed desktop dimensions.
- Avoid unnecessary dependencies.
- Keep TypeScript strict and avoid `any` unless justified.
- Reuse existing tokens and components.
- Validate loading, empty, error, disabled, and success states where relevant.
