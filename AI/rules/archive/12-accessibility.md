# Accessibility Rules

Migration note: reusable accessibility guidance from this file was preserved here for reference and should be promoted to knowledge or project rules when needed. Original guidance is preserved below.

- Target WCAG 2.2 AA.
- Ensure all interactive controls are keyboard operable.
- Provide programmatic names and clear focus order.
- Maintain sufficient contrast.
- Do not encode meaning by color alone.
- Support browser zoom and large text.
- Announce meaningful asynchronous changes where needed.
- Prefer native elements over custom controls.
