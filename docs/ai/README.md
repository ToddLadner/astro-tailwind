# AI project context

This directory contains durable, repository-specific facts for human contributors and coding harnesses. It does not orchestrate models or providers.

- `project.md`: goals, scope, and maturity.
- `stack.md`: runtime and dependency conventions.
- `architecture.md`: verified structure and data flow.
- `design-system.md`: CSS and token conventions.
- `commands.md`: development and validation commands.
- `known-issues.md`: verified limitations and validation baseline.
- `decisions.md`: durable project decisions.
- `handoffs/`: bounded recovery notes for unfinished work.

AI Workbench owns task preparation, routing, budgets, validation records, and failure packets. `AGENTS.md` remains the entry point for repository instructions.
