# Astro Tailwind Project

## Goal

Maintain an Astro-based playground for developing and evaluating interface components, CSS tokens, layouts, and interaction patterns.

## Current Scope

- Reusable Astro components under `src/components/`.
- Demonstration and experiment pages under `src/pages/`.
- A CSS-first Tailwind 4 theme and custom utilities under `src/css/`.
- Small browser-side interaction modules and inline scripts.
- A minimal Node test suite for server-side helpers.

## Maturity

This is an active playground rather than a documented production application. Some pages and components are experiments, and presence in the repository does not by itself establish a stable API.

## Source Of Truth

Implementation files, `package.json`, `astro.config.mjs`, `tsconfig.json`, and `biome.json` take precedence over this summary. Update this context when those files materially change.
